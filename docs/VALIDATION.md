# v2.0.0 验证记录

日期：2026-11-01，America/Los_Angeles。

## 功能确认

当前Wi-Fi、蓝牙、扬声器已确认可用，该套EFI作为第二版发布。以上为本机使用结果，不保证不同硬件或后续系统版本。

## 本机只读检查

- macOS26.7.2 / 25G332；Ryzen9 8940HX，8核16线程；系统信息中的CPU名称已正确显示AMD。
- NullMoth2.6.6四个驱动加载，Metal3与8GB显存已识别；未执行全套图形应用验证。
- MtkWlan0.12.1、MtkWlanNative0.4.15已加载，Wi-Fi接口en1存在。
- MtkBt0.2.4、BlueToolFixup2.7.2、LegionBtFix0.3.0已加载；蓝牙状态On，具有真实控制器地址。公开文档不包含该MAC地址。
- AppleALC1.9.8、SimpleHDA1.0.0已加载；系统列出Built-in Output / Internal Speakers，为默认输出；内置麦克风设备也已列出，但录音未实测。
- 外屏当前报告4096×2304渲染 / 2048×1152桌面 / 180Hz，串流关闭；指针偏大仍存在。
- awdl0接口不存在；当前MT7925驱动不支持隔空投送。

## 发布配置

发布前仅移除未重启测试的nvcursor=0参数，保留Wi-Fi、蓝牙、音频和所有其余EFI配置。该回滚后的参数与当前运行参数保持一致；不把实验性软件指针作为成功修复发布。

公开副本仅清理SMBIOS机器身份和密码哈希/盐；历史配置、日志、私人回滚文件和私人数据均不包含在仓库中。NVIDIA系统侧驱动、显示偏好、联系人数据也不包含在EFI中。

## 检查范围

检查plist解析、启用引用路径、EFI文件SHA256、源文件一致性、原始SMBIOS残留；从GitHub重新拉取后复核。静态检查不代替实际启动、稳定性、睡眠、耳机、录音、全部蓝牙外设或USB-C测试。
